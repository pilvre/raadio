See on Raadiosalvesti tutvustusleht, mitte sinu salvesti. Kui ühendasid oma fork'i Cloudflare'iga, vali projektis Pages (mitte Worker) ja seadetes Root directory web, Build output public, build command tühi – siis tuleb siia sinu salvestite leht. Juhend: raadio.mastering.ee.
Teade: ERR muutis oma raadiosaitide arhitektuuri ja ERR-i jaamade kava senine laadimisloogika ei toimi. Uues versioonis saab lisada ERR-i jaamade kava otse ERR-i lehelt järjehoidja-nupuga (juhend on Kava all ERR-i jaama juures).
Vaja on uuendada: terminalis (Windowsi puhul PowerShell) kirjuta raadio update; Cloudflare'i puhul vajab GitHubis uuendust ka oma koopia → Sync fork → Update branch.

Mis see on?

Sinu personaalne „kassettmakk“. Kõik toimub sinu arvutis – keegi teine sinu valikuid ega salvestusi ei näe.

Vali kavast

Terve saade iga kord või üks episood. Soovi korral ka kordused.

Taimerid

Mis tahes jaam, nädalapäevad ja kellaajad

Kuula telefonist

Pleier jätab meelde, kus pooleli jäid. Kiirus 1–2×, kerimine, lukustuskuva nupud.

Ka ilma võrguta

Laadi saade telefoni ja kuula ükskõik kus. Või salvesta MP3 failina.

Podcast-voog (RSS)

Privaatne voog podcastirakendusse – salvestused laaditakse ise telefoni ja töötavad ka Android Autos ning CarPlay's.

Otse-eeter ja pooleli saated

Kuula või salvesta jaama otse või kuula pooleli salvestust algusest – see uueneb jooksvalt.

Koristab ise

Hoia alles nt 2 viimast saadet – vana kustub, kui uus on valmis. Lukusta saade, mida tahad alles hoida.

Sinu arvutis

Mac, Windows, Linux või kodune NAS (Docker; sobib ka Raspberry Pi). Salvestused jäävad arvutisse või soovi korral sinu Cloudflare'i konto pilveruumi.

Jaamad: Raadio Kuku, Vikerraadio, Raadio 2, Klassikaraadio, Raadio 4, Raadio Tallinn, Sky Plus, Retro FM, Rock FM, Äripäeva raadio – uusi saab lisada.

Paigaldus

Arvuti peab salvestamise ajal sees olema – ideaalselt sobib nt kodus pidevalt töötav lauaarvuti.

  1. Kleebi käsk TerminaliPowerShelli ja vajuta Enter. Installer paigaldab vajadusel ffmpeg-i ja Pythoni (Homebrew kaudu – kui Homebrew'd pole, juhatab brew.sh-i)Pythoni ja ffmpeg-i (winget kaudu)ffmpeg-i ja Pythoni (paketihalduriga – võib küsida arvuti parooli) ja küsib: vali 1) Siin arvutis ning pane veebilehele kasutajanimi ja parool.
  2. Kui Windows küsib, luba tulemüüri reegel (muidu telefon lehte ei näe) ja nõustu unerežiimi väljalülitamisega vooluvõrgus.
  3. Installer näitab lõpus kaks aadressi: samas arvutis http://localhost:8788, telefonis nt http://192.168.1.103:8788 (telefon peab olema samas Wi-Fi võrgus). Ava leht ja logi sisse kasutajanime ja parooliga, mille installerile andsid (vaikimisi kasutajanimi raadio). Ununes? TerminalisPowerShellis käsk raadio parool näitab kasutajanime ja laseb parooli lähtestada.
  4. Lisa leht telefoni avaekraanile (nt iPhone: Jaga → Lisa avaekraanile) – siis käitub see nagu äpp.
  5. Veebiliideses on 4 sakki: Kava, Taimerid, Salvestused ja Minu saated. Vali kavast saated või lisa taimer. (Salvesti olekut näed arvutis, kui kirjutad TerminaliPowerShelli aknasse raadio ja vajutad Enter.)

    Sakk „Salvestused“ kuvab kõiki salvestatud episoode ja nende mahte. Saate saad alla laadida MP3 failina või täielikult kustutada; Cloudflare'i konto (või Tailscale'i) puhul saad selle salvestada ka (telefoni) brauseri mällu – teine vajutus ikoonile kustutab selle mälust. Lukuikooniga lukustatud saade ei kustu automaatselt (nt saade, mida tahad hiljem uuesti kuulata).

    Sakk „Minu saated“ kuvab salvestamiseks valitud saadete nimistut. Allpool saad iga saate või kõigi saadete kohta tellida RSS-voo, mille saad lisada podcast-pleierisse ja soovi korral saated kohe alla laadida. Cloudflare R2 puhul saad kuulata ka otse internetist, sõltumata asukohast.
  1. Kleebi ülal olev tekst NAS-i konteinerirakendusse (QNAP: Container Station → Applications → Create; Synology: Container Manager → Project → Create; mujal docker compose up -d) ja muuda: parool (RAADIO_PASS), NAS-i aadress koduvõrgus (RAADIO_HOST) ning kaustad, kuhu salvestused ja seaded NAS-is lähevad. Salvestuste kaust peab asuma olemasoleva ühiskausta all (QNAP: /share/<ühiskaust>/…, Synology: /volume1/<ühiskaust>/…) – kõige kindlam on see enne File Stationis luua, muidu võib Docker selle teha süsteemikettale.
  2. Käivita. NAS laeb alla valmis konteineri (~150 MB) – see võtab minuti-paar.
  3. Ava telefoni või arvuti brauseris http://<NAS-i aadress>:8788 ja logi sisse kasutajanime ja parooliga. Edasi on kõik sama mis teistel: Kava, Taimerid, Salvestused, Minu saated, podcasti-voog.
  4. Kui lehel on „⬆ Uuendus saadaval“, vali konteinerirakenduses Recreate (või docker compose pull && docker compose up -d). Seaded ja salvestused jäävad NAS-i kaustadesse alles. Kodust väljas kuulamiseks sobib Tailscale'i NAS-i pakett.
  1. Loo Cloudflare'is (vajadusel tee esmalt tasuta konto) Storage & Databases → R2 Object Storage → Create bucket, nt nimega raadio. Seejärel Manage API tokens → Create API token: õigus Object Read & Write, vali ainult see bucket.
  2. Kleebi ülal olev käsk TerminaliPowerShelli, vajuta Enter ja vali 2) Cloudflare R2. Avanevasse seadete faili pane konto ID ning tokeni Access Key ID ja Secret, seejärel käivita käsk uuesti.
  3. Kui sul pole GitHubis kontot, siis tee see (tasuta). Järgmisena tee GitHubis Raadiosalvesti koodist koopia (fork). Koopias on kõik koos: salvesti, sinu isiklik veebileht (kaust web) ja see tutvustusleht (kaust site, seda pole sul vaja). Cloudflare'is avaldad ainult kausta web: Compute → Workers & Pages → Create → Pages → Connect to Git → vali oma koopia. Valikutes Root directory web, build output public, build command tühi.

    NB! Vali kindlasti Pages, mitte Worker (Cloudflare pakub vaikimisi Workerit), ja ava Build settings all Root directory (advanced), et sinna web kirjutada. Kui see jääb tühjaks, avaneb sinu aadressil hoopis see tutvustusleht – siis muuda projekti seadetes (Settings → Build) Root directory ära ja tee uus deploy.
  4. Cloudflare Pages'i seadetes lisa saladused (tüüp Secret) AUTH_USER (kasutajanimi) ja AUTH_PASS (parool) ning tee uus deploy. Ava …pages.dev aadress telefoni- või arvutibrauseris ja lisa soovi korral avaekraanile.

Küsimusi on rohkem

See kõik tundub metsikult keeruline, ma ei saa midagi aru.

Pole hullu, lootust siiski on. Lihtsamas valikus on sisuliselt kaks sammu: kleebi üks käsk Terminali aknasse (Windowsis PowerShelli) ja vasta paarile küsimusele. Kõik muu teeb installer ise.

Või kutsu AI appi, kui julged:

  • AI-abiline (ChatGPT, Claude, Gemini vms) selgitab samm-sammult, mida teha. Kopeeri talle näiteks: „Loe https://raw.githubusercontent.com/pilvre/raadio/main/AGENTS.md ja aita mul Raadiosalvesti oma arvutisse paigaldada. Ma ei ole tehnikainimene – seleta lihtsalt.“
  • AI-agent (nt Claude Code, Codex, Cursor) saab paigalduse sinu loal ise ära teha ja hiljem ka seadistada või vigu otsida. Fail AGENTS.md on kirjutatud just talle: seal on kogu taust, ülesehitus ja levinud mured.

Üks reegel: ära kirjuta paroole ega Cloudflare'i võtmeid chatti – need sisestad ise, kui installer küsib. Hea agent teab seda niikuinii.

Kuidas kuulata kodust väljas (kohalik režiim)?

Tailscale (tasuta) ühendab telefoni ja arvuti turvaliselt ka kodust väljas – ilma ruuteri seadistamiseta. Paigalda see mõlemasse, logi sama kontoga sisse ja käivita arvutis terminalis tailscale serve --bg 8788. Siis avaneb leht aadressil https://<arvuti>.<tailnet>.ts.net – https-iga töötab ka telefoni laadimine.

Kas autos saab kuulata (Android Auto, CarPlay)?

Jah, podcastina. Lülita lehel „Minu saated“ → Podcast sisse ja lisa aadress rakendusse AntennaPod (Android, Android Auto) või Apple Podcasts (iPhone, CarPlay). Rakendus laeb salvestused telefoni ja autos kuulad neid nagu tavalisi podcaste – ka ilma võrguta. Feed on privaatne ja salajase võtmega.

Kui palju ruumi salvestused võtavad?

Tund saadet on umbes 28 MB (mono MP3, 64 kbps). Säilitust saab seada saate kaupa – nt hoia alles 2 viimast – või kustub vaikimisi 14 päeva pärast.

Kuidas salvesti peatada või eemaldada?

Terminalis (Windowsis PowerShellis): raadio stop peatab, raadio start käivitab uuesti. Eemaldamiseks peata teenus ja kustuta kaust (~/Raadiosalvestaja või %LOCALAPPDATA%\Raadiosalvestaja). Juhised: README.

Miks peab arvuti sees olema?

Salvestamine toimub sinu arvutis, mitte pilves – nii jäävad valikud ja salvestused sulle. Arvuti võib olla lukus, aga mitte unerežiimis.
