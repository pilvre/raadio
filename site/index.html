Mida see teeb

Kõik toimub sinu enda arvutis – keegi teine sinu valikuid ega salvestusi ei näe.

Vali kavast

Terve saade iga kord või üks episood. Soovi korral ka kordused.

Taimerid

Mis tahes jaam, nädalapäevad ja kellaaeg – nt E–R 7–9. Kava pole vajagi.

Kuula telefonist

Pleier jätab meelde, kus pooleli jäid. Kiirus 1–2×, kerimine, lukustuskuva nupud.

Ka ilma võrguta

Laadi saade telefoni ja kuula bussis või lennukis. Või salvesta MP3 failina.

Otse-eeter ja pooleli saated

Kuula jaama otse või pooleli salvestust algusest – see uueneb jooksvalt.

Koristab ise

Hoia alles nt 2 viimast saadet – vana kustub, kui uus on valmis. Pikad saated tundide kaupa.

Jaamad: Raadio Kuku, Vikerraadio, Raadio 2, Klassikaraadio, Raadio 4, Raadio Tallinn – uusi saab lisada.

Paigaldus

Arvuti peab salvestamise ajal sees olema – sobib nt kodus pidevalt töötav Mac mini või lauaarvuti.

  1. Kleebi käsk TerminaliPowerShelli ja vajuta Enter. Paigaldaja paigaldab vajadusel ffmpeg-i ja Pythoni (Homebrew kaudu – kui Homebrew'd pole, juhatab brew.sh-i)Pythoni ja ffmpeg-i (winget kaudu) ja küsib: vali 1) Siin arvutis ning pane veebilehele parool.
  2. Kui Windows küsib, luba tulemüüri reegel (muidu telefon lehte ei näe) ja nõustu unerežiimi väljalülitamisega vooluvõrgus.
  3. Paigaldaja näitab lõpus aadressi, nt http://192.168.1.20:8788. Ava see telefonis samas Wi-Fi võrgus ja logi sisse.
  4. Lisa leht telefoni avaekraanile (iPhone: Jaga → Lisa avaekraanile) – siis käitub see nagu äpp.
  5. Vali kavast saated või lisa taimer. Oleku näed arvutis, kui kirjutad TerminaliPowerShelli raadio ja vajutad Enter.
  1. Loo Cloudflare'is (tasuta konto) R2 → Create bucket, nt nimega raadio. Seejärel Manage API tokens → Create API token: õigus Object Read & Write, ainult see bucket.
  2. Kleebi ülal olev käsk TerminaliPowerShelli, vajuta Enter ja vali 2) Cloudflare R2. Avanevasse seadete faili pane konto ID ning tokeni Access Key ID ja Secret, seejärel käivita käsk uuesti.
  3. Tee GitHubis koopia (fork) ja ühenda see Cloudflare'is: Workers & Pages → Create → Pages → Connect to Git. Root directory web, build output public, build command tühi.
  4. Pages'i seadetes lisa saladused AUTH_USER (kasutajanimi) ja AUTH_PASS (parool) ning tee uus deploy. Ava …pages.dev aadress telefonis ja lisa avaekraanile.

Kasulik teada

Kuidas kuulata kodust väljas (kohalik režiim)?

Tailscale (tasuta) ühendab telefoni ja arvuti turvaliselt ka kodust väljas – ilma ruuteri seadistamiseta. Paigalda see mõlemasse, logi sama kontoga sisse ja käivita arvutis terminalis tailscale serve --bg 8788. Siis avaneb leht aadressil https://<arvuti>.<tailnet>.ts.net – https-iga töötab ka telefoni laadimine.

Kui palju ruumi salvestused võtavad?

Tund saadet on umbes 28 MB (mono MP3, 64 kbps). Säilitust saab seada saate kaupa – nt hoia alles 2 viimast – või kustub vaikimisi 14 päeva pärast.

Kuidas peatada või eemaldada?

Terminalis (Windowsis PowerShellis): raadio stop peatab, raadio start käivitab uuesti. Eemaldamiseks peata teenus ja kustuta kaust (~/Raadiosalvestaja või %LOCALAPPDATA%\Raadiosalvestaja). Juhised: README.

Kasutad AI-agenti (Claude Code, Cursor, Codex …)?

Anna agendile fail AGENTS.md – selles on tööriista taust, ülesehitus, paigaldus, levinud muudatused ja veaotsing. Näiteks: „Loe https://raw.githubusercontent.com/pilvre/raadio/main/AGENTS.md ja aita mul Raadiosalvestaja paigaldada.“ Repo kloonimisel loevad paljud agendid selle ise.

Miks peab arvuti sees olema?

Salvestamine toimub sinu arvutis, mitte pilves – nii jäävad valikud ja salvestused sulle. Arvuti võib olla lukus, aga mitte unerežiimis.
